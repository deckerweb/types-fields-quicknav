# Data and privacy

The plugin stores dtfq_settings per website: provider switches, feature and add-on switches, frontend/content switches, excluded content post types, deletion preference, excluded role keys, excluded user IDs and schema version. Deactivation keeps settings. No custom tables, own REST endpoints, cron tasks or telemetry. The bundled Library stores shared settings, managed-install records, user view preferences and caches under its own namespaced keys. Its optional online catalog is off by default; enabling it requests the configured GitHub catalog. Catalog installation/update actions contact the selected package source. Toolbar navigation itself makes no external requests. The bundled updater checks published GitHub releases through the WordPress update workflow; GitHub receives ordinary request metadata such as the requesting IP address. It does not activate automatic updates. Draft releases are not offered as updates.
